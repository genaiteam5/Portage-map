# Portage-map

블로동 고분군 디지털 프로타주 & 컬렉션 체험 사이트.

## 실행 방법 (인터넷 불필요)

- 폴더 안의 `index.html` 을 Chrome 으로 더블클릭하면 바로 열립니다.
- 또는 `start.command` (맥) 더블클릭 → `http://localhost:8000` 으로 열림.

## 에셋

- `assets/services/` 서비스 페이지 사진, `assets/bullroarer-web.mp4` 하단 영상
- `assets/stamps/*.js` 는 `assets/*.svg` 도판을 file:// 에서도 읽도록 data URI 로 변환한 사본입니다.
  도판 SVG 를 바꾸면 이 파일들도 다시 만들어야 합니다.
